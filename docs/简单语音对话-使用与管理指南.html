SimpleVoiceChat 使用与管理指南

项目 当前版本口径
模组名称SimpleVoiceChat（简单语音对话）
模组版本1.1.0
游戏版本Vintage Story 1.22.3
语音协议协议 V4；Opus 为首选编码，是否允许 ADPCM 回退由服务器配置决定
安装范围客户端和服务器均需安装同一版本
文档核对日期2026-08-13

SimpleVoiceChat 提供接近度语音、耳语/正常/大喊模式、自定义频道、玩家本地音量与静音、录音、音频处理、权限管理和容量保护。服务器只负责鉴权、路由和转发，客户端负责采集、播放及本地设置。

重要： 当前发行包使用协议 V4。客户端与服务器版本不一致时，语音握手可能被拒绝；请不要同时放置多个 SimpleVoiceChat 压缩包。

一、安装与首次进入

  1. 关闭 Vintage Story 客户端和服务器。
  2. 删除 Mods 目录中旧的 SimpleVoiceChat 压缩包，只保留目标版本。
  3. 将 SimpleVoiceChat-v1.1.0.zip 原样放入客户端和服务器的 Mods 目录，不要解压模组包。
  4. 先启动服务器，再启动客户端并进入世界。
  5. 第一次使用时，聊天框会提示按 ' 进入设置。该提示不会直接打开窗口。
  6. 按 ' 打开首次设置向导。欢迎页可以选择“跳过初始设置，进入设置窗口”，也可以按“取消”关闭或按“确认”开始配置。

SimpleVoiceChat 不依赖 Simple Voice Chat、VS Director 或 SimpleVoiceChat_VSDirectorIntegration。基本语音功能只需要本模组；VS Director 同时存在时才会自动启用可选录制集成。

向导依次配置输入设备、输出设备、发言方式、麦克风音量测试、噪声门和自由麦触发阈值。窗口为居中弹窗，不会遮住整个游戏视口。按键触发默认使用 N，完成或跳过后，按 ' 会打开主设置窗口。

默认按住说话键为 N，Alt + N 保留为按键触发/自由麦模式切换。需要修改按键时，请在游戏按键设置中的 Simple Voice Chat 分类修改；首次设置向导和语音识别页面均不提供按键捕获控件。

三、发言方式与自由麦

按键触发：按住绑定的按键（默认 N）时发送语音。

语音触发通话（自由麦）：麦克风持续监听输入，只有音量超过触发阈值才开始发送。向导中的单条矩形音量条实时显示麦克风声音，并提供两个滑块手柄：噪声门用于过滤底噪，触发阈值用于决定何时开始发送。玩家可以边说话边调整两个手柄。

四、主窗口与设置页

主窗口是紧凑的主页：顶部居中显示 Simple Voice Chat，下方是“设置”“语音识别”“频道”，拥有 controlserver 权限的玩家还会看到“管理员”。主页底部是一排正方形图标按钮和两个快速下拉菜单：

  • 麦克风图标：切换本地麦克风开启/静音。
  • 扬声器图标：切换拒听/恢复收听。
  • 眼睛图标：显示/隐藏右下角 HUD。
  • 录音图标：开始或停止实际录音。开始时会先弹出录音模式选择。
  • 快速频道：选择当前频道；空值表示不选择频道。
  • 快速发送形式：仅接近度、仅当前频道、接近度和当前频道。

打开弹窗后只显示当前层，关闭弹窗会返回上一层，不会堆叠多个可操作窗口。

设置（音频）

“设置”页使用单行控件，包含输入设备、输出设备、播放音量和麦克风增益。自由麦的噪声门和触发阈值在首次设置向导中配置，也可继续在对应设置项中调整。滑块内部直接显示数值，数值不会被滑块遮挡。

“麦克风测试”用于本机测试，不会发送到服务器，也不会写入录音文件：点击“开始录音”开始，点击“停止录音”结束，再点击“播放录音”或“停止播放”检查扬声器。测试音频保存在内存中，离开游戏后不会保留。

下面的开关包括麦克风静音、拒听、自适应抖动缓冲、遮挡/传播修正和性能模式。噪声抑制与回声消除配置目前不在界面中显示；遮挡效果在服务器强制开启时不能关闭。

五、语音识别与文字聊天

语音识别默认关闭，并且完全在玩家客户端配置。进入主页的“语音识别”，打开功能开关，从下拉菜单选择服务商，再填写该服务商所需的 API Key、模型、接口地址或模型路径。切换服务商时，每个服务商的配置会分别保存。启用后按住 V 录音，松开后识别并把文字发送到当前聊天频道。

服务商类型默认模型或路径默认接口
阿里百炼云端qwen3-asr-flashhttps://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
硅基流动云端FunAudioLLM/SenseVoiceSmallhttps://api.siliconflow.cn/v1/audio/transcriptions
Deepgram云端nova-3https://api.deepgram.com/v1/listen?model=nova-3&smart_format=true
Vosk本地解压后的模型文件夹不需要
Whisper本地Whisper.cpp GGML .bin 模型文件不需要

文档与下载：阿里百炼、SiliconFlow、Deepgram、Vosk 模型、Whisper.cpp 模型。设置页中的“打开下载页面”位于模型提示下方的独立一行。

Vosk：下载的压缩包必须完整解压，填写包含 am、conf 等内容的模型文件夹路径。Whisper：填写实际 GGML .bin 模型文件路径，不要只填写所在文件夹；如果下载内容是压缩包，也要先解压。Windows、Linux 和 macOS 均可填写本平台的正常绝对或相对路径，只要游戏进程具有读取权限。

隐私：云端 API Key 以明文保存在本机 SimpleVoiceChat.Client.json，请勿分享该文件。云端识别音频由客户端直接发送给所选服务商，不经过 SimpleVoiceChat 服务端。Vosk 和 Whisper 在本机处理，不需要 API Key，也不会把识别音频上传给识别服务商。

六、接近度语音

接近度语音不要求加入频道。服务器默认范围为：

模式默认距离用途
耳语8 格近距离私语。
正常说话18 格日常交流。
大喊35 格通知较远处玩家。

服务器管理员可用 /svc setrange whisper|talk|shout <格数> 修改范围；服务器还会限制最高范围。

七、频道页面与分页

所有玩家都可以查看自己有权看到的频道列表。管理员可以查看全部频道；普通玩家看不到“隐藏”频道，除非已经加入该频道。开放频道可直接加入，密码频道会弹窗要求输入密码，隐藏频道只能通过频道主持人或所有者邀请加入。

  1. 进入主页后点击“频道”。
  2. 在顶部搜索框输入频道名称或 ID，然后点击“搜索”。输入过程中不会立即刷新列表；点击右侧“取消”会清空搜索并恢复全部可见频道。
  3. 每个频道卡片显示名称、人数、锁定状态、频道类型和唯一 ID。点击 ID 可复制到剪贴板。
  4. 点击卡片或“选择频道”按钮选择当前频道；点击齿轮图标打开频道设置；对未加入的开放/密码频道点击加入。

频道列表每页最多显示 6 行。列表底部的“上一页 / 第 X / Y 页 / 下一页”用于切换页面，按钮在第一页或最后一页自动禁用。底部玩家图标打开玩家列表，“创建频道”打开创建频道弹窗。

创建频道

默认情况下所有玩家都可以创建频道。服务器管理员可以使用 /svc channelallow off 禁止普通玩家创建，使用 /svc channelallow on 恢复。创建频道时填写名称、可选密码并选择类型：

类型列表可见性加入方式
开放可见玩家可直接加入。
密码可见输入正确密码后加入。
隐藏普通玩家不可见，管理员可见只能通过频道所有者或频道主持人邀请。

创建者即为频道所有者。频道 ID 使用不重复且不会复用的 channel-数字 格式，例如 channel-12。频道最大 100 名成员，默认最多 3 名同时发言者。

频道角色与操作

角色权限
所有者创建者；可邀请、移出、频道禁言/封禁较低角色，设置角色，锁定/解锁和解散自己的频道。当前图形界面的改名控件位于管理员页面。
频道主持人可邀请玩家，并对低于自己的成员执行移出、禁言、解除禁言、封禁和解除封禁；不能修改所有者。
成员可以发言和收听（受频道席位、禁言和服务器管制影响），可以离开频道。
只听可以收听，不能在该频道发言。
封禁不能加入或使用该频道。

玩家列表中的音量滑块和静音按钮只改变本机收听效果。玩家设置齿轮中的管理操作会按照当前玩家在频道中的权限过滤；普通玩家不会看到管理员专属的全服管制操作。

离开、转移所有权与解散

在频道操作中点击“离开频道”或“解散频道”后，必须先确认。确认弹窗左侧为“取消”，右侧为“确认”；即使频道只有一名玩家，解散也不会跳过确认。

如果频道所有者在频道中仍有其他成员，服务器会再次要求选择：

  • 转移频道所有者：目标必须是当前频道中的玩家。
  • 删除频道：会弹出解散确认，确认后删除频道。

所有者不会在离开后随机转移给某个玩家。所有者离开且频道没有其他成员时，确认后频道会被移除。关闭任一弹窗只返回上一个窗口，底层窗口不会继续拦截鼠标。

八、玩家列表与实际录音

频道页底部的玩家图标打开玩家列表。玩家列表每页最多显示 6 名玩家，支持按玩家名称或 ID 搜索，搜索必须点击“搜索”，右侧“取消”恢复全部玩家。每名玩家卡片包含本地音量滑块、静音图标和设置齿轮；设置和静音不会改变服务器权限。

主页底部的录音图标才是实际录音功能。点击后选择“仅输入”“输入+输出”或“多人分轨”，再次点击录音图标停止并保存 WAV 文件。录音保存到：

AppData\Roaming\VintagestoryData\ModData\SimpleVoiceChat

“麦克风测试”与实际录音不同：设置页测试音频只保存在内存中，用于开始/停止录制和播放检查，不生成文件。

多人分轨服务器配置

先启动服务器一次，让 Vintage Story 在服务器数据目录的 ModConfig/SimpleVoiceChat.Server.json 生成配置。在现有 JSON 中修改下列字段；不要创建重复字段，也不要用片段覆盖其他服务器设置：

{
  "EnableRecorderCapture": true,
  "MaxRecorderListeners": 1,
  "MaxRecorderEgressKbps": 4096
}

保存后，由拥有 controlserver 的管理员执行 /svc reload，或重启服务器。EnableRecorderCapture 必须为 true；MaxRecorderListeners 是录制管理员接收端上限，不是说话玩家数量，当前单管理员会话保持 1；MaxRecorderEgressKbps 是每个录制管理员接收压缩语音转发的带宽预算，不限制 WAV 文件大小，允许范围为 512-8192，默认且推荐 4096。它仍受服务器总出口 MaxServerEgressKbps 限制。

多人分轨要求录音者拥有 controlserver。Ctrl + F9 会直接打开多人分轨面板，即使主设置页关闭；等待三个 UDP 时钟样本后开始录制。面板会保留在屏幕上，显示同步或录制状态，并在开始后提供“停止录制”按钮。服务器会创建一个未来的统一单调时钟锚点。每名玩家在同一会话目录中各有一条补齐静音的单声道 WAV，session.json 保存共同时间线。管理员也可使用 /svc recording start|stop|status，开始和结束均会写入 /svc audit。

单人游戏可测试相同流程，内置服务器使用同一配置；成功后只会写入 local.wav，因为没有远端玩家。单人模式的 Vintage Story 可能使用虚拟 UDP 端点；若一秒内没有 UDP 时钟回包，模组会自动通过可靠控制通道完成同样的三次时钟采样。多人时，必须在状态显示正在录制后让每名玩家说话，并点击停止录制，才会写入 <玩家UID>.wav、session.core.json 和 session.json。OBS 的 SimpleVoiceChat Player Voice 只录制混合玩家语音并回传时间点，不会自行启动多人分轨或生成玩家 WAV。

OBS 安装与自动对齐

将对应系统的插件包解压到 OBS 安装根目录：Windows 使用 obs-plugins/64bit/simplevoicechat_obs.dll；Linux 保留包内 lib/.../obs-plugins 路径；macOS 将 PlugIns/simplevoicechat_obs.plugin 放入 OBS.app/Contents/PlugIns。重启 OBS 后，在“来源”中添加一次 SimpleVoiceChat Player Voice，再在高级音频属性中把它分配到所需 OBS 音轨。麦克风、游戏、桌面和音乐继续使用 OBS 原有音源。

多人分轨会话与 OBS 录制必须有重叠时间，启动先后不限。插件会回传 OBS 实际开始录制的 UTC 时间，会话目录写入 obs-sync.json 并更新 session.json.obsAlignment。剪辑导入逐玩家 WAV 时使用 wavZeroMinusObsStartMilliseconds，公式为 obsTimeMs = wavTimeMs + wavZeroMinusObsStartMilliseconds；该设计不会随着玩家数量占用更多 OBS 音轨。

九、管理员页面与权限

拥有 Vintage Story controlserver 权限并完成语音握手的玩家，主页顶部会看到“管理员”按钮。管理员页面不创建频道入口；频道创建仍通过频道页底部“创建频道”，或使用服务器命令。管理员可以查看全部频道和玩家，并执行服务端再次鉴权的管理操作：

  • 频道：添加/移出成员、设置只听/成员/频道主持人、禁言/解除禁言、封禁/解除封禁、锁定/解锁、改名、解散。
  • 玩家：临时禁言、强制拒听、持久禁言、解除持久禁言、全服屏蔽、解除全服屏蔽。

管理员通过“添加成员”把玩家加入频道时，目标玩家以普通成员加入，不会获得频道所有者身份。频道所有者仍是创建频道的玩家，服务器管理员通过 controlserver 权限执行管理操作。

由外部频道提供器管理的频道，其成员、角色和名称由外部系统决定，不能在本模组中本地添加、移出、改角色、改名、离开或解散；管理员仍可执行允许的锁定、频道禁言和封禁操作。

十一、服务器管理员命令

以下命令要求 controlserver 权限。尖括号表示必填参数。频道 ID 使用 channel-数字，可在频道页点击 ID 复制或用 /svc channels 查询。

命令作用
/svc status查看服务器开关、范围、频道数量和全服管制数量。
/svc enable / /svc disable启用或停用全部语音转发。
/svc channelallow on|off允许或禁止普通玩家创建频道，默认是 on。
/svc setrange whisper|talk|shout <格数>修改接近度语音范围。
/svc channels列出频道 ID、类型、所有者、人数、发言席位和锁定状态。
/svc channelcreate <名称>创建开放持久频道；图形界面可额外选择密码或隐藏类型。
/svc channelinvite <频道ID> <玩家>向指定频道发送邀请。
/svc channelleave <频道ID>以命令方式请求玩家离开指定频道。
/svc channeladd <频道ID> <玩家或UID> / /svc channelremove ...添加或移出频道成员。
/svc channelrole <频道ID> <玩家或UID> listenonly|member|moderator设置频道角色；不能通过此命令设置所有者。
/svc channellock <频道ID> / /svc channelunlock <频道ID>锁定或解锁频道。
/svc channelmute|channelunmute <频道ID> <玩家或UID>在指定频道禁言或恢复玩家。
/svc channelban|channelunban <频道ID> <玩家或UID>在指定频道封禁或解除封禁玩家。
/svc tempmute <玩家> [秒] / /svc deafen <玩家> [秒]临时禁言或强制拒听，默认 60 秒。
/svc adminmute|adminunmute <玩家或UID>添加或解除持久全局禁言。
/svc forceblock|unforceblock <玩家或UID>添加或解除全服语音屏蔽。
/svc adminmutes查看持久禁言和全服屏蔽列表。
/svc playerdiag <玩家> / /svc diag查看玩家连接或服务器路由诊断。
/svc audit / /svc metrics reset查看最近管理审计或重置滚动指标。
/svc reload重新加载并归一化服务器配置；失败时保留旧配置。

主要配置SimpleVoiceChat.Server.json、SimpleVoiceChat.Client.json。
管理审计SimpleVoiceChat.Audit.json；记录管理操作，不记录语音内容。
实际录音AppData\Roaming\VintagestoryData\ModData\SimpleVoiceChat；仅客户端本地保存。

服务端转发压缩语音帧，不常态解码、混音或保存语音载荷。本模组不提供端到端加密，传输保护依赖 Vintage Story 底层连接。实际录音属于玩家主动操作，应按服务器和活动隐私规则管理。

可选 VS Director 集成

SimpleVoiceChat 和 VS Director 可以分别独立安装。两者同时存在时，本模组会在运行时发现 VS Director 的语音 API；不需要安装 SimpleVoiceChat_VSDirectorIntegration，SimpleVoiceChat 也不会因为缺少 VS Director 而停止加载。

服务器所有者必须在 SimpleVoiceChat.Server.json 中设置 EnableDirectorProximityCapture: true。VS Director 自身也必须开启相应的回放或离屏语音捕获选项。回放区域捕获期间，位于活动导演监听器回放区块范围内的所有发言都会进入导演音轨，包括频道目标语音；没有活动回放区域时，导演捕获仍按耳语/正常/大喊距离工作。玩家主动录音和导演录制均可能保存语音内容。

回放区域捕获使用独立的 MaxDirectorEgressKbps 带宽预算（默认 4096），每个监听器最多 32 条导演语音流。

麦克风测试没有文件这是设计行为。设置页“麦克风测试”只在内存中录制；需要保存文件时使用主页录音图标。

十四、权限速查

问题答案
普通玩家可以创建频道吗？默认可以，管理员可用 /svc channelallow off 关闭。
谁是频道所有者？创建频道的玩家。管理员添加成员不会自动成为所有者。
谁可以邀请玩家？频道所有者和频道主持人；管理员可使用管理员添加操作。
普通玩家能看到隐藏频道吗？不能。必须被邀请，或已经是该频道成员。
频道主持人等同管理员吗？不等同。频道主持人只管理所属频道；管理员拥有 controlserver 的全服管理权限。
所有者离开后谁接任？所有者必须在弹窗中指定当前频道成员，或确认删除频道；不会随机接任。
