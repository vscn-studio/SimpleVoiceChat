SimpleVoiceChat provides proximity voice chat, whisper/normal/shout modes, custom channels, per-player local volume and muting, recording, audio processing, permission management, and capacity safeguards. Normal voice is authenticated, routed, and relayed by the server; multi-track recording is authoritatively hosted and written by the server while clients handle capture, playback, OBS markers, and downloads.

Important: The current release uses protocol V9. The client and server must use compatible SimpleVoiceChat builds or the voice handshake is rejected. Do not install multiple SimpleVoiceChat ZIP files at the same time.

1. Installation and First Launch

  1. Shut down the Vintage Story client and server.
  2. Delete old SimpleVoiceChat ZIP files from the Mods directory, leaving only the version you intend to use.
  3. Place SimpleVoiceChat-v1.2.7-pre.2.zip unchanged in the Mods directory on both the client and server. Do not extract the mod archive.
  4. Start the server first, then start the client and join the world.
  5. On first use, the chat box prompts you to press ' to open settings. The prompt itself does not open a window.
  6. Press ' to open the initial setup wizard. On the welcome page, you can choose "Skip Initial Setup and Open Settings," select "Cancel" to close the wizard, or select "Confirm" to begin configuration.

SimpleVoiceChat does not require Simple Voice Chat, VS Director, or a separate integration mod. This package provides the base voice features by itself; optional VS Director capture activates only when VS Director is present and the server enables it.

The wizard configures the input device, output device, speaking method, microphone level test, noise gate, and voice-activation threshold in sequence. It appears as a centered dialog and does not cover the entire game viewport. Push-to-talk uses N by default. After you complete or skip the wizard, pressing ' opens the main settings window.

3. Speaking Methods and Voice Activation

Push-to-talk: Transmits voice while you hold the assigned key (default: N).

Voice activation (open mic): The microphone continuously monitors input but begins transmitting only when the level exceeds the activation threshold. A single rectangular level meter in the wizard shows the live microphone level and includes two slider handles: the noise gate filters background noise, while the activation threshold determines when transmission begins. You can adjust both handles while speaking.

4. Main Window and Settings Page

The main window is a compact home page. Simple Voice Chat is centered at the top, with "Settings," "Speech Recognition," and "Channels" below it. Players with the controlserver privilege also see "Administration." The bottom of the home page contains a row of square icon buttons and two quick-selection menus:

  • Microphone icon: enables or mutes the local microphone.
  • Speaker icon: deafens or undeafens local voice playback.
  • Eye icon: shows or hides the HUD in the lower-right corner.
  • Record icon: starts or stops a recording to file. When starting, you first choose a recording mode.
  • Quick Channel: selects the current channel; a blank value means no channel is selected.
  • Quick Transmission Mode: Proximity Only, Current Channel Only, or Proximity and Current Channel.

Only the current dialog layer is displayed. Closing a dialog returns to the previous layer instead of leaving multiple interactive windows stacked on screen.

Main-window extensions (client API)

Other client mods can register text buttons, image buttons, or custom controls through SimpleVoiceChatModSystem.ClientSettingsExtensions. Extensions appear below the quick-control row containing the HUD visibility button, are sorted by Order, and wrap automatically using each control's PreferredWidth. Extension heights are constrained to 28-96px and the minimum width is 28px; image buttons default to a 42px square. The home page height follows the actual row heights and rows beyond the visible area can be reached with the mouse wheel without overlap or overflow.

var voiceChat = api.ModLoader.GetModSystem<SimpleVoiceChatModSystem>();
voiceChat.ClientSettingsExtensions.RegisterButton(
    new VoiceSettingsExtensionButton(
        "example.button", "Example", () => OpenExample(),
        order: 100, preferredWidth: 160));

For the same image-button treatment used by the built-in quick controls, register VoiceSettingsExtensionImageButton:

voiceChat.ClientSettingsExtensions.RegisterControl(
    new VoiceSettingsExtensionImageButton(
        "example.image",
        new AssetLocation("example", "gui/icon.png"),
        () => OpenExample(), order: 100));

A mod can also register an independent extension window. SimpleVoiceChat supplies the centered panel, title, close button, clipping, and the common 4px rounded background; extension buttons and other controls remain square:

voiceChat.ClientSettingsExtensions.RegisterWindow(
    new VoiceSettingsExtensionWindow(
        "example.window", "Example",
        context => context.Composer.AddStaticText(
            "Content", CairoFont.WhiteSmallText(),
            ElementBounds.Fixed(0, 0, context.ContentWidth, 30))));
voiceChat.ClientSettingsExtensions.ShowWindow("example.window");

These APIs are client-only. Registration IDs may contain letters, digits, ., _, and -. Closing the main settings dialog also releases an open extension window.

Settings (Audio)

The "Settings" page uses single-row controls for the input device, output device, playback volume, and microphone gain. The noise gate and activation threshold for voice activation are configured in the initial setup wizard and can also be adjusted later in their corresponding settings. Slider values are displayed inside the sliders without being obscured by the handles.

"Microphone Test" is a local-only test. It does not transmit to the server or write a recording file. Select "Start Recording" to begin, "Stop Recording" to finish, and then "Play Recording" or "Stop Playback" to check your speakers. Test audio is held in memory and is discarded when you leave the game.

The switches below include Microphone Mute, Deafen, Adaptive Jitter Buffering, Occlusion/Propagation Correction, Environmental Voice Effects, and Performance Mode. This release does not bundle an RNNoise native library, so the Noise Suppression selector is disabled and audio falls back to the built-in AGC/gate processing; on Windows, a compatible rnnoise.dll may be installed at %APPDATA%\VintagestoryData\ModData\SimpleVoiceChat\native\rnnoise.dll, after which the selector becomes available. Echo cancellation is not currently available. Occlusion cannot be disabled when the server enforces it.

Settings pages use a shared scroll viewport when their content is taller than the window. Use the mouse wheel or the visible scrollbar; controls, text inputs, and drop-down popups are clipped to the viewport while scrolling.

6. Proximity Voice Chat

Proximity voice chat does not require channel membership. The default server ranges are:

ModeDefault rangeUse
Whisper8 blocksPrivate conversation at close range.
Normal18 blocksEveryday conversation.
Shout35 blocksReaching players farther away.

Server administrators can change these ranges with /svc setrange whisper|talk|shout <blocks>. The server also imposes a maximum range.

Proximity voice applies a client-side distance gain curve during playback: volume stays normal nearby, gradually falls as the speaker approaches the mode boundary, and reaches silence at the boundary. The server still forwards only to listeners inside the configured range (the spatial query has an approximately one-block routing buffer), so the fade does not expand network forwarding and does not turn channel voice into positional voice. With "Selected Channel" only, no proximity fade is applied; with "Proximity and Channel", the server gives a recipient that matches both conditions the higher-priority channel path, while other proximity recipients use the fade.

The client computes distance from the received speaker position and the local player's position. Position updates and fast movement can leave the final audio frames briefly behind the player's visual position, but they do not change the server routing boundary. Distance gain is multiplied with player volume, master volume, mute/deafen state, and environment effects; increasing a local volume cannot make an out-of-range speaker audible.

Underwater and Equipment Voice Effects

The server determines whether a speaker is underwater and whether a configured helmet or mask is equipped. Effects are marked on voice packets by the server, so clients cannot claim equipment they are not wearing. The client applies the effect during local playback; multi-track WAV files retain the unprocessed speech. Environmental effects can be disabled locally, while the server can disable them for everyone or allow underwater processing for channel voice.

Server administrators edit these fields in ModConfig/SimpleVoiceChat.Server.json and run /svc reload or restart afterward:

{
  "EnableEnvironmentalVoiceEffects": true,
  "ApplyUnderwaterEffectsToChannels": false,
  "EquipmentVoiceEffectRules": [
    { "Slot": 2, "ItemCodePattern": "armor-head-*", "Effect": 0 },
    { "Slot": 1, "ItemCodePattern": "clothes-face-*mask*", "Effect": 1 }
  ]
}

Slot values 0/1/2 mean Head/Face/ArmorHead; Effect values 0/1 mean Helmet/Mask. Rules are checked in order, the first match wins, and */? wildcards are supported. A pattern without a domain matches the item path in any domain.

Nearby Public Chat

Administrators can enable "Nearby chat messages" and set the "Chat visibility range" in the Administration page, or edit EnableProximityChatText and ProximityChatRange in the server configuration. When enabled, ordinary public chat is delivered only to players in the same dimension and within the configured range; the sender always sees their own message. Channel chat, commands, system notifications, and administrator messages are not changed.

7. Channel Page and Pagination

All players can view the channels they are authorized to see. Administrators can view every channel. Ordinary players cannot see Hidden channels unless they have already joined them. Open channels can be joined directly, Password channels prompt for a password, and Hidden channels require an invitation from a Channel Moderator or Owner.

  1. Select "Channels" on the home page.
  2. Enter a channel name or ID in the search box at the top, then select "Search." The list does not refresh as you type. Select "Cancel" on the right to clear the search and restore all visible channels.
  3. Each channel card shows its name, member count, lock state, channel type, and unique ID. Select the ID to copy it to the clipboard.
  4. Select a card or the "Select Channel" button to make it the current channel. Select the gear icon to open channel settings. For an Open or Password channel you have not joined, select Join.

The channel list displays up to six rows per page. Use "Previous / Page X / Y / Next" at the bottom of the list to change pages. Previous and Next are disabled automatically on the first and last pages. The player icon at the bottom opens the player list, and "Create Channel" opens the channel-creation dialog.

Creating a Channel

By default, all players can create channels. A server administrator can prevent ordinary players from creating channels with /svc channelallow off and restore permission with /svc channelallow on. When creating a channel, enter a name, optionally enter a password, and choose a type:

The creator becomes the Channel Owner. Channel IDs use the unique, never-reused format channel-<number>, for example channel-12. A channel can contain up to 100 members and allows up to three simultaneous speakers by default.

The volume slider and mute button in the player list affect only local playback. Management actions under a player's settings gear are filtered according to your permissions in that channel. Ordinary players do not see server-wide moderation actions reserved for administrators.

Leaving, Transferring Ownership, and Disbanding

Selecting "Leave Channel" or "Disband Channel" under channel actions always requires confirmation. The confirmation dialog places "Cancel" on the left and "Confirm" on the right. Disbanding never skips confirmation, even when the channel contains only one player.

If other members remain in a channel when its Owner tries to leave, the server requires another choice:

  • Transfer Channel Ownership: the target must be a current member of the channel.
  • Delete Channel: opens the disband confirmation dialog and deletes the channel after confirmation.

Ownership is never transferred to a random player when the Owner leaves. If no other members remain, the channel is removed after the Owner confirms leaving. Closing any dialog returns only to the previous window; windows underneath do not continue intercepting mouse input.

8. Player List and Recordings to File

The player icon at the bottom of the Channels page opens the player list. The list displays up to six players per page and supports searching by player name or ID. You must select "Search" to run a search; "Cancel" on the right restores the full player list. Each player card includes a local volume slider, mute icon, and settings gear. These volume and mute settings do not change server permissions.

The record icon at the bottom of the home page controls recording to file. Select it, then choose "Record input only," "Record input and output," or "Multi-track speakers." Input only saves the local microphone. Input and output creates a stereo WAV with the microphone on the left and local playback on the right. Multi-track speakers does not create one mixed WAV; it creates one independent WAV per speaker inside a session directory. Select the home-page record icon again to stop a normal recording. Once a multi-track session is active, the recommended stop control is the Stop Recording button in the multi-track panel.

Ordinary local recordings remain in the client data directory. Authoritative multi-track files are stored under ModData/SimpleVoiceChat/Recordings in the server data directory; clients keep only OBS markers and downloaded copies.

"Microphone Test" is separate from recording to file. Test audio on the Settings page is kept only in memory for start/stop recording and playback checks; it does not create a file.

Multi-track Server Configuration

Start the server once so Vintage Story creates the configuration in ModConfig/SimpleVoiceChat.Server.json under the server data directory. Edit these existing JSON fields; do not add duplicate fields or overwrite the server's other settings with this example:

{
  "EnableRecorderCapture": true,
  "RecorderCheckpointSeconds": 5,
  "MaxRecorderSessionMinutes": 360,
  "MaxRecorderClockSkewMilliseconds": 2000,
  "MaxRecorderDownloadKbps": 8192
}

Save the file, then run /svc reload as an administrator with controlserver, or restart the server. Before start, every handshaken participant must report at least three stable clock samples and pass the UTC skew check. Encoded frames use the reliable control channel while the server checkpoints WAV files and recording-state.json. An administrator crash, disconnect, or reconnect does not stop the session; any online administrator can stop it. A server restart repairs and marks an interrupted session recovered.

Multi-track recording requires controlserver and EnableRecorderCapture. Open the panel with Ctrl + F9 and start only after participant status is ready. Administrators may also use /svc recording start|stop|status|list|download <session-id>. The server finalizes files before sending the end timeline and chunks. The client creates session.json only after WAV files, session.core.json, and recording-state.json arrive. Tracks are named PlayerName-UID.wav; sequence gaps and disconnect events are retained in the manifest.

Single-player uses the same server-hosted workflow. A speaker must actually transmit voice to create PlayerName-UID.wav. Frames that never reach the server during a disconnect cannot be reconstructed, but other tracks remain aligned. OBS SimpleVoiceChat Player Voice exposes one mixed player-voice bus and does not increase the fixed OBS track count.

OBS Installation and Alignment

Extract the platform-matched plugin package into the OBS installation root: Windows uses obs-plugins/64bit/simplevoicechat_obs.dll; Linux retains the package's lib/.../obs-plugins path; macOS places PlugIns/simplevoicechat_obs.plugin in OBS.app/Contents/PlugIns. Restart OBS, add SimpleVoiceChat Player Voice once from Sources, then assign it to the desired OBS track in Advanced Audio Properties. The plugin and game client must run as the same operating-system user so their local named pipe or Unix socket can connect. Keep microphone, game, desktop, and music on their normal OBS sources. The plugin exposes only one mixed player-voice bus; the mod-generated WAV files provide per-player separation.

The multi-track session and OBS recording must overlap, in either start order. The server and OBS host should use NTP so UTC stays close. At the end, request the in-game stop first and wait for server finalization plus client download before stopping OBS, or let the exporter wait for the files. Recovered sessions can be listed with /svc recording list and downloaded with /svc recording download <session-id>.

After OBS stops recording, the plugin obtains the final OBS video and waits for the session's finalized session.json, obs-sync.json, and player WAV files. It automatically creates <video>-<session>-multitrack.mkv and a matching .fcpxml beside the OBS video; a numeric suffix is added if either target already exists. The MKV retains the OBS video and existing audio streams and adds one unprocessed PCM stream per player. The FCPXML references the original video and all WAV files and places every player on an independent track using the synchronization offset. obs-export.json in the session directory records waiting, exporting, completed, or failed, the input/output paths, alignment offset, and any error. Only completed means both export files are finished. Keep OBS open until then.

Exported Files and DaVinci Resolve Editing

FilePurpose
<video>.mp4The original OBS video referenced by the FCPXML.
...-multitrack.fcpxmlA timeline description, not embedded media; this is the recommended Resolve import entry point.
...-multitrack.mkvAn archive/checking file containing the OBS video, existing OBS audio, and added per-player PCM tracks.

obs-sync.jsonThe time anchor between the actual OBS recording start and the server/WAV start; it is not imported into Resolve.

obs-export.jsonExport status, input/output paths, alignment offset, and error details; begin editing only after completed.
  1. Open obs-export.json in the session directory and confirm "status": "completed". Do not treat the mere presence of a filename as proof that export finished.
  2. Open DaVinci Resolve, create or open a project, and choose File > Import Timeline > Import FCPXML. Select the generated .fcpxml. Do not manually drag the WAV files onto the timeline first.
  3. On the Edit page, verify that the OBS video is on V1 and that every player is on an independent audio track. The FCPXML has already placed each WAV at the synchronized position. For example, wavZeroMinusObsStartMilliseconds = 5880 places WAV time zero at 5.880 seconds in the video.
  4. If the imported timeline contains both an OBS microphone/desktop voice mix and the per-player WAV tracks, mute or remove the mixed voice track to avoid hearing each voice twice. Retain game audio, ambience, weather, music, or other OBS sources as needed.
  5. Apply volume, EQ, noise reduction, compression, and edits independently on each player track. This workflow does not generate subtitles or assign subtitle colors automatically. After creating subtitles, use the track name or player UID to assign speaker colors manually.

The FCPXML refers to the MP4 and WAV files by absolute path. Do not move, rename, or delete the MP4, FCPXML, or session directory before import. If files must be moved, use Relink Selected Clips in Resolve's Media Pool and point it to the new video and session directories. A positive wavZeroMinusObsStartMilliseconds means WAV time zero is after the OBS recording start; a negative value means it is before it. FCPXML handles either case automatically. Use the MKV for archival or checking in a multitrack-capable player; prefer the FCPXML for Resolve editing.

Before importing into a new Resolve project, set the timeline frame rate to match the OBS source, such as 60 FPS for a 60 FPS recording. The FCPXML derives its frame rate from the source video, while audio synchronization uses millisecond and sample positions rather than manual frame counting. Existing 24 FPS projects may lock the timeline setting; create a matching timeline if Resolve reports a frame-rate mismatch.

9. Administration Page and Privileges

Players who have the Vintage Story controlserver privilege and have completed the voice handshake see an "Administration" button at the top of the home page. The Administration page does not provide a channel-creation entry point. Channels are still created with "Create Channel" at the bottom of the Channels page or by using a server command. Administrators can view all channels and players and perform these server-authorized management actions:

  • Channels: add or remove members; assign Listen Only, Member, or Channel Moderator roles; mute or unmute; ban or unban; lock or unlock; rename; and disband.
  • Players: temporarily mute, forcibly deafen, persistently mute or unmute, and block or unblock server-wide.

When an administrator uses "Add Member" to put a player in a channel, the target joins as an ordinary Member and does not become the Channel Owner. The player who created the channel remains its Owner; server administrators perform management actions through their controlserver privilege.

For channels managed by an external channel provider, the external system controls membership, roles, and names. These properties cannot be changed locally through this mod, and such channels cannot be left or disbanded locally. Administrators can still perform permitted lock, channel-mute, and ban actions.

Optional VS Director Integration

SimpleVoiceChat and VS Director can be installed independently. When both are present, this mod discovers the VS Director voice API at runtime. SimpleVoiceChat_VSDirectorIntegration is not required, and SimpleVoiceChat continues loading normally when VS Director is absent.

The server owner must set EnableDirectorProximityCapture: true in SimpleVoiceChat.Server.json. The matching replay or offscreen voice-capture option must also be enabled in VS Director. During replay-region capture, every voice packet from a speaker inside the active director listener's configured replay chunk region enters director tracks, including channel-targeted packets. Without an active replay region, director capture keeps the normal whisper/talk/shout range. Player-initiated recording and director capture can both preserve voice content.

Replay-region capture uses the separate MaxDirectorEgressKbps budget (default 4096) and up to 32 director streams per listener.

Ctrl + F9 has no usable Start button or remains at 0/3Enter the world and confirm that the voice handshake completed, the recording client has controlserver, and EnableRecorderCapture is true on the current server. Run /svc reload or restart after editing the configuration. Single-player mode tries the reliable control channel after one second; if the count still does not increase, check client/server versions and game logs.
SimpleVoiceChat Player Voice exists, but no per-player WAV appearsThe OBS source is only a mixed monitoring bus. Start server-hosted multi-track recording, wait for participant readiness, have each player actually transmit voice, then stop and wait for download. Use /svc recording list and /svc recording download <session-id> for recovered or previously completed sessions.
No MKV or FCPXML is generatedInspect obs-export.json in the session directory. Confirm that the OBS recording overlaps the multi-track session, OBS and the game run as the same operating-system user, and the original video still exists. Keep OBS open until completed; when status is failed, use the error field for diagnosis.
Resolve reports Media OfflineThe FCPXML uses absolute paths. Restore the original locations, or use Relink Selected Clips in the Media Pool and point Resolve to both the OBS video and the session directory containing the player WAV files.
Voices play twice after importThe mixed voice track inside the OBS video is playing together with the player WAV tracks. Mute or remove the mixed voice track while retaining any game audio, music, or other OBS tracks that are still needed.
The video is 60 FPS, but the Resolve timeline is 24 FPSSet a new project's timeline frame rate to 60 FPS before import, or create a timeline matching the source video. FCPXML aligns audio by millisecond offset and sample position, so no manual conversion from timeline frame numbers is required.
Whisper is missing or reports an invalid model pathInstall the matching Simple Voice Chat: Local Whisper client extension, then select the actual .bin model file. Confirm that the path uses the current platform's syntax and that the game can read it.
VS Director replay or offscreen output has no voiceEnable EnableDirectorProximityCapture on the server, enable the matching capture option in VS Director, ensure the director player has controlserver, and check the log for "optional VS Director integration is unavailable." No separate integration mod is needed.
The Owner leaves a channelIn a channel with multiple members, the Owner must transfer ownership to a current member or confirm deletion. Ownership is never transferred randomly. Both leaving and disbanding require confirmation.

14. Quick Permissions Reference

QuestionAnswer
Can ordinary players create channels?Yes, by default. Administrators can disable channel creation with /svc channelallow off.
Who is the Channel Owner?The player who created the channel. An administrator who adds a member does not automatically become the Owner.
Who can invite players?The Channel Owner and Channel Moderators. Administrators can use the administrative Add Member action.
Can ordinary players see Hidden channels?No. They must be invited or already be a member of the channel.
Is a Channel Moderator the same as an administrator?No. A Channel Moderator manages only their channels; an administrator has server-wide management privileges through controlserver.
Who takes over after the Owner leaves?The Owner must choose a current channel member in the dialog or confirm channel deletion. No one is selected at random.
