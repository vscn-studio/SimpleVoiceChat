SimpleVoiceChat User and Administration Guide

Item Documented Version
Mod name SimpleVoiceChat
Mod version 0.2.0
Game version Vintage Story 1.22.2
Installation scope Required on both the client and the server
Document verification date 2026-07-28

SimpleVoiceChat is a client-and-server voice chat mod designed for multiplayer servers and civilization simulation events. It provides proximity voice chat, temporary squads, civilization, command, diplomacy, staff, broadcast, and radio channels, together with per-player volume controls, role permissions, channel administration, moderation, and connection diagnostics.

Important: By default every player can create a channel. An administrator can disable this with /svc channelallow off. Channel visibility controls whether a channel is listed: open channels can be joined directly, password channels require a password, and hidden channels are only reachable through an invitation.

1. Installation and Joining a Server

  1. Close the Vintage Story client and server.
  2. Delete the older SimpleVoiceChat mod archive so that two versions are not loaded on the same side.
  3. Place SimpleVoiceChat-v0.2.0.zip in the client's Mods directory.
  4. Place the same archive in the server's Mods directory.
  5. Start the server, then start the client and join the world.
  6. After entering the world, press ' and confirm that the SimpleVoiceChat window opens.
  7. Open the Status page, confirm that the server handshake has completed, and check the UDP, RTT, and probe packet-loss information.

Important: Version 0.2.0 uses voice protocol V2 by default and is not compatible with 0.1.x clients. The server and every client participating in voice chat should use the same version. Do not rely on AllowLegacyProtocol or an ADPCM fallback as a substitute for a complete upgrade during a live event.

2. Default Key Bindings

Push-to-talk / voice activation Alt + N Toggles push-to-talk and voice activation. Voice activation continuously monitors the microphone and sends when the trigger threshold is exceeded.

Mute local microphone Ctrl + - Stops transmitting your microphone

The default push-to-talk binding is N and the mode toggle remains Alt + N. To change the key, use the Simple Voice Chat category of the game's control settings; the first-time setup guide no longer contains a key-capture field.

3. First-Time Setup and Microphone Check

  1. On first use, press ' to open the centered setup dialog. It is a modal panel and does not draw a full-screen opaque overlay over the game view.
  2. Select the microphone you actually use under Input Device. The mod restarts audio capture after the device is changed.
  3. Choose Push-to-talk or Voice activation. For Voice activation, use the single rectangular microphone meter with two draggable handles: Noise gate filters background noise, while Trigger threshold starts transmission when speech is loud enough.
  4. Adjust Playback Volume and Microphone Gain on the final levels step. The guide no longer uses a key-selection drop-down or a separate “continuous talk” option.
  5. Confirm that Mute and Deafen are not enabled.
  6. Use the microphone test controls to record, pause or stop, and play the captured clip. The test stays in memory and is not written to a file or sent to the server.
  7. Open the Status page and confirm that a connection has been established. Return to the game and hold N to test an actual conversation.

Note: Noise suppression and echo cancellation settings are intentionally hidden from the current interface. Basic high-pass filtering, gain control, soft limiting, the noise gate, and voice activity detection still work.

4. Proximity Voice Chat and Transmission Targets

Proximity voice chat does not require you to join a channel. The default ranges are shown below; server administrators can change these values.

Speaking mode Default range Suitable use
Whisper 8 blocks Private conversation at close range
Normal speech 18 blocks Everyday conversation
Shout 35 blocks Alerting nearby players from farther away

After joining a channel, first select the Current Channel on the Channels & Players page, then choose a transmission target:

Transmission target Who receives it Usage note
Proximity Only Players within range Audio is not sent to the current channel
Current Channel Only Members of the current channel who are allowed to listen Not limited by proximity range
Proximity and Current Channel Nearby players and members of the current channel A listener reached through both paths hears the audio only once

Important: Check your transmission target before participating in an event. When Current Channel Only or Proximity and Current Channel is selected, a local conversation may be transmitted to a civilization, staff, or broadcast channel.

5. Channel Types

Channel Default speaking rules How it is created
Squad Squad members can speak; defaults to a maximum of 12 members and 3 concurrent speaking slots Created automatically after an ordinary player sends an invitation and the other player accepts it
Civilization Members can speak; defaults to 3 concurrent speaking slots Created by an administrator or supplied by an external civilization mod
Command Only the owner and officers can speak; defaults to 2 concurrent speaking slots Created by an administrator
Diplomacy Authorized members can speak; defaults to 3 concurrent speaking slots Created by an administrator
Staff Members can speak; routing has a higher priority Created by an administrator
Broadcast Only the owner and officers can speak; other members should generally be assigned Listen Only Created by an administrator
Radio Membership and frequency semantics are defined by an administrator or external provider Created by an administrator or supplied by an external system

Note: A concurrent speaking slot is one speaker whose audio is actually being forwarded at a given moment. All eligible members can attempt to speak, but when a channel is busy they may be told that all speaking slots in the current channel are occupied and to try again later.

6. Creating and Using a Temporary Squad

Creating a New Squad

  1. Make sure squad channels are enabled on the server.
  2. Move close to the target player. The default required range is 4 blocks.
  3. Face the target player and enter /svc bind, or enter /svc bind <player name> directly.
  4. The target player receives a Squad Invitation panel in the lower-right corner.
  5. The target player must click Accept Invitation within 10 seconds, or can enter /svc accept.
  6. After the invitation is accepted, the system automatically creates a temporary squad channel and adds both players to it.
  7. Select the squad channel on the Channels & Players page, then choose Current Channel Only or Proximity and Current Channel as needed.

Leaving, Inviting, and Merging

Situation Rule
Not yet in a squad You can invite another player; accepting the invitation creates a new squad
Already an ordinary squad member You cannot invite additional members; only the squad owner or an officer can invite
Merging two existing squads Both the inviter and recipient must be an owner or officer of their respective squad, and the merged squad must not exceed the membership or channel limits
Leaving a squad Select Leave Channel in the interface, or enter /svc unbind
Disbanding a squad Only the squad owner or a server administrator can do this
Invitation is not handled It is automatically treated as declined after 10 seconds

Important: A squad invitation is not a way to freely create a formal channel. Ordinary players cannot enter a name, choose a channel type, or create a persistent channel. Accepting an invitation only creates a system-managed temporary squad.

7. Channel Roles and Ordinary Member Permissions

Role What the role can do What the role cannot do
Listen Only Listen to the channel and adjust its local volume Cannot speak in the channel or manage members
Member Speak and listen according to channel policy, select channels and transmission targets, and leave channels that are not externally managed Cannot create formal channels, change roles, lock or disband a channel, or manage other members
Officer Has member abilities; can invite squad members and mute, ban, or remove lower-ranking members in a channel Cannot change the owner or modify the owner's status
Owner Has officer abilities; can assign Listen Only, Member, and Officer roles; can lock, unlock, or disband the channel; can rename persistent channels Cannot override authoritative membership and name management performed by an external provider
Banned None Cannot join or use the channel

Ordinary players can adjust the local volume of individual players or mute them on the Channels & Players page. These settings affect only their own client. They do not change what anyone else hears and do not create a server moderation record.

8. Administrator Privileges and the Administration Interface

When a player has Vintage Story's controlserver privilege, an additional Administration page appears on the left side of the voice window. The client only displays the entry point; every operation is authorized again by the server.

Creating a Formal Channel

  1. Press ' to open the voice window, then open the Administration page.
  2. Enter a channel or civilization name in the Create Event Channel section.
  3. Select the Civilization, Command, Diplomacy, Staff, Broadcast, or Radio channel type.
  4. Click Create Channel. The creator becomes the channel owner, and the channel is saved as a persistent channel.
  5. Select a target player and the new channel, then use Admin Join Channel.
  6. Assign members the Listen Only, Member, or Officer role as required by the event.
  7. Return to Channels & Players or use /svc channels to check membership, speaking slots, and lock status.

Administrator Capabilities

Administrative scope Available operations
Server-wide voice chat Enable or disable voice chat, change whisper/normal/shout ranges, and reload configuration
Channel creation Create persistent Civilization, Command, Diplomacy, Staff, Broadcast, and Radio channels
Channel maintenance Add or remove members, change roles, rename, lock, unlock, and disband channels
Channel moderation Mute, unmute, ban, and unban within a channel
Temporary player moderation Temporarily mute or forcibly deafen a player; the interface defaults to 60 seconds, while commands can specify a duration in seconds
Persistent player moderation Persistently mute or unmute a player, and block or unblock a player server-wide
Diagnostics and auditing Inspect channels, player connections, codecs, rate limiting, routing metrics, and recent administrative actions

Important: Channels created by an external civilization or grouping provider are authoritatively managed by that external system. Administrators cannot locally add or remove members, change roles, rename, leave, or disband such channels through this mod. They can still lock a channel and apply channel mutes or bans.

The following administrative commands require the controlserver privilege. Angle brackets indicate required arguments; do not type the brackets themselves in the game.

/svc forceblock <player or UID>Adds a player to the persistent server-wide block list

Note: Channels can be renamed and disbanded through the voice administration interface. Use /svc channels first to find the channel ID required by a command.

Server configurationSimpleVoiceChat.Server.json

Administration auditSimpleVoiceChat.Audit.json

The server only forwards compressed voice audio. It does not routinely decode, mix, or record audio, and it does not store voice payloads. Administration audit entries record the time, operator, target, scope, and reason, but do not record voice content.

Important: This mod does not provide end-to-end encryption. Transport protection depends on the underlying Vintage Story connection. Server owners should still control access to server logs, configuration files, and audit files according to the event's privacy policy.

13. Quick Permissions Summary

Question Answer
Can ordinary players use proximity voice chat?Yes. No channel membership is required.
Can ordinary players create a temporary squad?Yes, but they must send an invitation and the other player must accept it within 10 seconds.
Can an ordinary squad member invite more members?No. After joining a squad, only the owner or an officer can invite.
Can ordinary players create Civilization, Command, or Broadcast channels?No. These formal channels can only be created by administrators with the controlserver privilege.
Is a channel owner the same as a server administrator?No. Owners can only manage channels they are authorized to manage. They cannot apply server-wide voice moderation or create new formal channels.
Can administrators manage the membership and names of external civilization channels?They cannot locally change members, roles, or names, but they can lock the channel and apply channel mutes or bans.
